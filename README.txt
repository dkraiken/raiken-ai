# Raiken AI Demo

Demo web latihan pilihan ganda dengan:
- floating AI overlay
- input link demo
- deteksi jumlah soal
- target nilai
- pemilihan jawaban otomatis
- perhitungan benar/salah

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. Tekan START AI atau tombol AI mengambang.
4. Masukkan target nilai, misalnya 85.
5. Tekan ANALISIS & JAWAB OTOMATIS.

Catatan:
Versi ini sengaja menggunakan soal lokal/demo. Input URL belum mengambil isi situs eksternal.
